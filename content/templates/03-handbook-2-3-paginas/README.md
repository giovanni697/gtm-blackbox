## Objetivo

Estruturar handbooks consultivos de 2-3 páginas para cada combinação (motion × momento da jornada). Cada handbook é um arsenal — não um manual.

## Quando usar

- Você está em ARPE e quer escalar venda consultiva sem aumentar dependência de heróis.
- Ramp-up de novos hires está acima de 4 meses.
- Pipeline depende de 1-2 vendedores top.

## O que este template entrega

- Estrutura padrão de handbook 2-3 páginas (KPI, definition of done, momentos críticos, cadência, hand-offs, FAQ).
- Lista canônica de 8-16 handbooks por operação madura.
- Checklist de qualidade.
