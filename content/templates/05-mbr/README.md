## Objetivo

Estabelecer ritual mensal disciplinado de identificação de gargalo (TOC) → análise de causa-raiz (Pensamento Lógico) → Plano de Ação → Roadmap atualizado.

## Quando usar

A partir de ARMV. MBR é foundational — sem ele, Loop de Melhoria Contínua não opera.

## O que este template entrega

- Pauta canônica de 90 minutos.
- Pré-leitura obrigatória 24-48h antes.
- Formato fixo de Plano de Ação.
- Follow-up estruturado.
